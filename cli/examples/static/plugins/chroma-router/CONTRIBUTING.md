# Contributing to Chroma-Router

The package is plain ESM (`index.js`) with no build step. Keep `version` in `package.json` and `chroma.plugin.json` in sync and bump both with any change. See [Versioning](https://docs.targapps.xyz/docs/chroma/contributing/versioning).

The plugin is vendored into the CLI at `Chroma/cli/plugins/chroma-router`; copy changes there when releasing.
